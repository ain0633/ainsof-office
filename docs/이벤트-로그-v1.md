# 이벤트 로그 v1

M1 T6에서 고정(2026-10-17). 게이트(`plugin/gate/gate.mjs`)가 `C:\ainsof\log\events-YYYY-MM-DD.jsonl`에 한 줄에 하나씩 덧붙인다. 오피스 화면(D17)은 이 형식만 읽는다.

기획서 3.7: `v`가 M1·M2 동안 바뀌지 않아야 오피스를 시작한다. 칸이나 종류를 바꾸면 `tests/gate.test.mjs`의 "v1 형식" 시험이 깨진다. 그때는 v를 올릴지 먼저 정한다.

## 공통 칸

| 칸 | 값 |
|---|---|
| `v` | `1` |
| `ts` | UTC ISO 시각 (`2026-10-17T00:46:12.345Z`) |
| `id` | UUID |
| `type` | 아래 7가지 |
| `actor` | `role`(예: `ainsof-office:developer`), `session_id`, `agent_id`(하위 봇일 때) |
| `data` | 종류별 칸 |

## 종류

| type | 언제 | data |
|---|---|---|
| `tool.call` | 봇이 도구를 부르기 직전(게이트 판정) | `tool`, `target`(가린 요약), `decision`(allow·ask·deny), `rule`, `reason`(allow가 아닐 때), `hit`(걸린 글자, 있을 때) |
| `tool.result` | 도구가 끝난 뒤 | `tool` |
| `task.assigned` | 운영실이 봇에게 작업 카드를 넘김 | `to`(봇 역할), `card`(카드 id 또는 null), `model`·`effort`(부를 때 지정했을 때만) |
| `task.result` | 봇이 결과를 돌려줌 | `from`, `status`(done·needs_approval·blocked·failed·unknown) |
| `agent.start` / `agent.stop` | 하위 봇이 시작·끝 | 없음 |
| `compact` | 세션 맥락 압축 | 없음 |

기획서 3장에 있던 `approval.*`, `msg`, `gate.block`, `cost.sample`, `decision.recorded`, `meeting.*` 는 v1에 없다. 승인 요청은 `tool.call`의 `decision: "ask"`로, 막음은 `decision: "deny"`로 읽는다. 필요해지면 v2에서 더한다.

## 쓰지 않는 것

파일 내용, 도구 출력 원문, 키·개인정보(가림 처리, 기획서 3.4).
