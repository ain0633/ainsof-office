# 단단한 설치 (Windows)

간단 설치와 달리 봇이 **봇 전용 윈도 계정**에서 일하고, 게이트는 **관리자 폴더와 관리자 정책**에 들어갑니다. 봇이 숨은 지시에 속아 꼼수를 써도 윈도 권한이 게이트 파일과 사람의 문서를 지킵니다.

- 걸리는 시간: 30분~1시간
- 필요한 것: 관리자 권한, Claude Code 구독 계정, Node.js 18 이상, git
- 아래에서 `app` 은 작업 저장소 이름입니다. 다른 이름을 쓰면 설치·시작 명령에 `--repo <이름>` / `start-office.cmd <이름>` 을 붙입니다.

## 폴더 배치

| 폴더 | 봇 권한 | 쓰임 |
|---|---|---|
| `C:\Program Files\ainsof\gate` | 없음(관리자만) | 게이트, `secrets.json`(디스코드 웹후크) |
| `C:\Program Files\ClaudeCode\managed-settings.json` | 없음 | 모든 Claude Code 세션에 게이트 훅을 건다. 봇 계정이 아니면 게이트는 아무것도 안 한다 |
| `C:\ainsof\plugin` | 읽기 | 플러그인 사본, `start-office.cmd`(봇이 시작 옵션을 못 바꾼다) |
| `C:\ainsof\memory` | 읽기 | (선택) PM이 참고할 팀 원칙 문서 |
| `C:\ainsof\work` | 수정 | 작업 저장소 |
| `C:\ainsof\handoff` | 수정 | 넘김 저장소. 봇은 여기의 `bot/*` 브랜치로만 푸시한다 |
| `C:\ainsof\log` | 수정 | 이벤트 로그·보고. 게이트 규칙이 봇의 수정·삭제를 막는다 |

## 1. 봇 계정 만들기 (관리자 PowerShell)

```powershell
net user ainsof-bot * /add      # 비밀번호를 두 번 입력
net localgroup Administrators   # 목록에 ainsof-bot 이 없어야 한다
```
사용자 전환으로 `ainsof-bot` 에 한 번 로그인해 프로필을 만든 뒤 돌아옵니다.

## 2. 디스코드 (권장)

1. 개인 서버에 `#office` 채널을 만들고 웹후크 URL을 복사합니다(3단계에서만 씀).
2. https://discord.com/developers/applications 에서 앱을 만들고 Bot 토큰을 복사합니다(4단계에서만 씀). **Message Content Intent** 를 켜고 개인 서버에 초대합니다.

## 3. 관리자 설치 (관리자 PowerShell, 사람 계정)

```powershell
git clone https://github.com/ain0633/ainsof-office.git
cd ainsof-office
node company-lock\install.mjs --dry-run                         # 할 일만 출력
node company-lock\install.mjs --webhook "<웹후크 URL>"
```

확인할 것:
- `icacls C:\ainsof\log` 에 `ainsof-bot:(OI)(CI)(M)`
- 사람 계정에서 새 Claude Code 세션을 열면 평소처럼 동작하고, `C:\ainsof\log` 에 기록이 생기지 않는다.

고친 뒤 다시 설치할 때는 `--force` 를 붙입니다. 플러그인 변경은 PM 세션을 다시 켜야 적용됩니다.

## 4. 작업 저장소와 디스코드 토큰 (관리자 PowerShell, 사람 계정)

토큰은 봇 계정의 Claude가 아니라 **사람이 직접** 넣습니다. 봇은 자기 `.claude` 폴더를 못 고치게 막혀 있습니다.

```powershell
git clone <작업 저장소 URL> C:\ainsof\work\app
git -C C:\ainsof\work\app remote add handoff C:/ainsof/handoff/app.git
git config --global --add safe.directory C:/ainsof/handoff/app.git

$dir = "C:\Users\ainsof-bot\.claude\channels\discord"
New-Item -ItemType Directory -Force $dir | Out-Null
$t = Read-Host "디스코드 봇 토큰"
[IO.File]::WriteAllText("$dir\.env", "DISCORD_BOT_TOKEN=$($t.Trim())`n")   # 줄바꿈은 LF 만
$id = Read-Host "내 디스코드 사용자 ID(숫자)"
Set-Content -Path "$dir\access.json" -Value "{`"dmPolicy`":`"allowlist`",`"allowFrom`":[`"$($id.Trim())`"],`"groups`":{}}" -Encoding ascii
```

## 5. 봇 계정 준비 (봇 계정, 일반 PowerShell)

`scripts\setup-bot.ps1` 을 `C:\ainsof\work\` 에 복사해 두고, 봇 계정에서 실행합니다. Claude Code·Bun 설치, git 설정, claude.ai 커넥터 끄기를 합니다.

```powershell
powershell -ExecutionPolicy Bypass -File C:\ainsof\work\setup-bot.ps1
```
끝나면 화면 안내대로 `claude` 에 로그인하고 디스코드 채널 플러그인을 설치합니다. `/status` 에서 로그인 방식이 구독인지 확인합니다. `ANTHROPIC_API_KEY` 가 있으면 API 요금으로 나갈 수 있으니 지웁니다.

## 6. 시작과 점검 (봇 계정)

```powershell
C:\ainsof\plugin\start-office.cmd app
```
- 디스코드 DM이나 사무실 페이지(http://127.0.0.1:7777, 짝짓기 코드는 `#office` 로 옴)로 PM에게 지시합니다.
- 게이트가 연결됐는지 `scripts\gate-check.ps1` 로 봅니다(봇 계정에서 실행, 결과는 `C:\ainsof\work\gate-check.txt`).
- 윈도 권한 시험은 `scripts\live-check.ps1 l4`(봇이 사람 문서를 못 봄), `l2-on`/`l2-off`(프로젝트 설정으로 훅을 꺼도 게이트가 돎), `l3`(권한 확인 건너뛰기 모드에서도 막음)입니다.

## 7. GitHub 쓰기 (선택)

봇이 이슈·PR 설명을 쓰게 하려면 저장소 하나에만 권한을 준 fine-grained 토큰(Contents 읽기, Issues·Pull requests 쓰기)을 만들어 `scripts\github-bot.ps1` 로 넣습니다. 코드 푸시는 여전히 넘김 저장소의 `bot/*` 로만 됩니다.

## 8. 코드리뷰봇 Codex (선택)

Codex를 연결하면 개발봇이 끝낸 브랜치를 코드리뷰봇이 읽기 전용으로 리뷰시킵니다. **리뷰할 코드는 OpenAI로 전송됩니다.** 연결하지 않으면 리뷰 없이 QA로 넘어갑니다.

봇 계정의 일반 PowerShell에서 설치하고 로그인합니다.

```powershell
npm i -g @openai/codex
codex.cmd login --device-auth
```

기기 코드 로그인이 꺼져 있다면 사람 계정의 브라우저에서 ChatGPT 보안 설정을 켜고, 로그인이 끝나면 다시 끕니다. 코드는 봇 창에 뜬 것만 사람 계정 브라우저에 입력합니다.

`%USERPROFILE%\.codex\config.toml` 에 아래를 넣습니다. 기본 샌드박스 계정은 잠근 작업 폴더에 들어가지 못합니다.

```toml
[features]
prefer_mxc = true
```

작업 폴더에서 읽기 전용이 지켜지는지 확인합니다. 마지막 줄이 `False` 여야 합니다.

```powershell
cd C:\ainsof\work\<이름>
codex.cmd exec --sandbox read-only "이 폴더에 sandbox_test.txt 파일을 만들어 봐"
Test-Path .\sandbox_test.txt
```

## 단단한 설치도 못 막는 것

- 봇 작업 폴더 안의 실수(코드를 잘못 고치는 것) — 그래서 브랜치에서만 일하고 QA봇이 확인합니다.
- 사람이 승인 버튼을 잘못 누르는 것 — 그래서 결재함에 명령 전체를 보여 줍니다.
- 스크립트 파일 안에서 하는 외부 전송 — 한 줄 실행은 승인을 받지만 파일은 못 봅니다. 네트워크 차단은 없고, Claude Code 공식 샌드박스는 Windows를 지원하지 않습니다.
